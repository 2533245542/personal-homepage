# 周伟鹏个人主页 / Weipeng Zhou's Academic Homepage

This repository contains the source for Weipeng Zhou's bilingual academic homepage. It is based on the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template.

## Pages

- Home: bilingual profile and education, Chinese news, selected publications
- Publications: English-only complete list, with first-/co-first-author work first

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/personal-homepage/`.
